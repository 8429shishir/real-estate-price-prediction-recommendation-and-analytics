## 🏠 Real Estate Price Prediction and Recommendation System
<h3>📘 Project Overview</h3>

This project is a Data Science Capstone Project that focuses on leveraging advanced data analysis and machine learning techniques to predict real estate property prices and recommend properties based on user preferences.

It encompasses the entire data science workflow — from data cleaning, feature engineering, and model building to deployment as a web application using Streamlit and AWS.
